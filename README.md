### 🚀 Мен жөнүндө
💡 Frontend иштеп чыгуучумун, **заманбап веб-сайттарды** жана ыңгайлуу интерфейстерди түзөм.  
⚡ Иштеген технологиялар: **HTML, CSS, JavaScript, TypeScript, React, Next.js**.  
🛒 Долбоорлорум: интернет-дүкөндөр (MegaShop, Ала-Тоо Маркет), саякат жана билим берүү сайттары.  
🎯 Дайыма жаңы нерселерди үйрөнөм жана **идеядан релизге чейин** продукт куруп чыгууну жакшы көрөм.
